# 随机评分筛选机制 · 设计草案

> 本文档整理自 2026-11-21 的讨论（v0.0.1classic 阶段）。
> 对应设计文档《幻想气象局.md》的「模拟原理」与「个人想法日记」：气象来自多次随机并由此筛选的最优解。
> 当前引擎（v1）只做了"单次抽样 + 日期种子"，本文描述的是它的下一阶段。

## 一、核心结构：提案 → 评分 → 择优

把"否决骰"改写成三段式。否决式的问题：容易全部被否决、或第一个候选就通过，调参困难；
评分式永远有输出，"离谱程度"可以被平滑调参。

1. **提案层**：每天从日期种子生成 N 个完整候选。
   候选 = 一组自包含字段（天气型、高低温、云量、风、事件标记……）。
   当前 `weather_engine.gd` 的 `day_report()` 单次抽样就是现成的提案器，重复 N 次即可。
2. **评分层**（核心，每项都是可独立调参的分量）：
   - **气候距离**：候选值对"跨月加权气候值"的偏离扣分；
     容差从当月记录区间导出（如 8 月允许 ±6℃，12 月 ±4℃）。
   - **连续性（惯性）**：与"昨日"差异越大扣分越多。
     现实天气系统生命期 2~5 天，这是消除"今天暴雨明天暴晒"跳变感的关键；
     可实现为马尔可夫转移概率，或等价的"与昨日相同加分、切换扣分"。
   - **稀缺性预算**：台风、寒潮等特殊事件给"月度配额"（由该月气候反常度决定），
     抽中即扣减，避免"天天台风"。整月配一个"戏剧性预算"参数，
     创作者可调"这个世界的天气有多疯狂"。
   - **一致性硬约束**（真正的否决骰）：低温≤高温、高温≤当月记录、
     整月雨天数与"平均降水天数"对齐等，违反直接重掷。
3. **择优层**：取最高分；或按分数加权抽取（保留一点混沌感）。

## 二、月度对账

整月跑完后统计雨天数量 vs 气候表「平均降水天数」、总降水 vs 「平均降水量」，
偏差太大就把剩余日期的权重向欠采样方向偏移（重要性采样 / 拒绝重抽）。
保证"7 月该有 13 个雨天"这类气候直觉。
注意保持按日期种子的确定性：配额状态本身也要由种子派生。

> v1 已知偏差的例证：7 月按日照算出的雨概率约 23%，但气候表里 7 月有 25.6 个降水天。
> 「平均降水天数」才是雨天先验的正源，日照更适合区分晴/阴。

## 三、种子设计

- `seed = hash(世界ID + 城市ID + 日期)`：
  不同世界/城市同一天天气独立；分享时"同一份 CSV + 同一策略 → 同一份天气历史"。
- 世界可以按《幻想气象局.md》所述：用本地化键名的逆编码→十进制数字化作为随机种子，
  乘以世界气候波动图（柏林图层叠加）。
- "真性伪随机"（实时时间随机）做成可选开关。

## 四、与「世界设置」骨架的衔接

设计文档里的世界层概念可以自然映射到本机制：

| 设计文档概念 | 在评分筛选中的位置 |
|---|---|
| 原始波动事件（每日全球数个，按缓冲/概率筛选数个起点） | 提案层的事件生成器 |
| 气候现象（规模/作用形状/天气规则/持续时间/迁移速度/路径关键帧） | 提案层候选的来源之一 + 评分层的高权重项 |
| 气候现象 × 城市天气乘数 | 评分层的气候距离项的输入 |
| 柏林函数图 + 双图重合区权重叠加 | 气候距离容差的空间调制（高海拔打破连续性） |

即：台风、季风等自定义气象成因，本质是**带出现条件的候选生成器 + 高权重评分项**。

## 五、让评分成为创作者可写的东西（远期）

评分函数用资源/脚本暴露（GDScript 可重载的 `score(candidate, context)`，或数据化权重表 CSV），
创作者可以定义"这个世界崇尚风暴"→ 风暴加分。

## 六、实现路线

- **v1（现状）**：单日独立抽样（日期种子 + 日照加权随机）。
- **v1.5**：加"昨日→今日"马尔可夫惯性；用「平均降水天数」定雨天先验，日照区分晴/阴。
- **v2**：月度配额对账 + 事件系统（台风/寒潮/锋面过境 + 对温度的冲击曲线）。
- **v3**：评分函数开放给创作者；与世界层波动图/气候现象打通。

## 七、更远的路线图（按分层）

- **近**：月视图日历（引擎确定性，整月可直接渲染）；温度四时点（2/8/14/20）曲线；
  雪天（低温 + 降雪天数）。
- **中**：天气型体系扩展（「气候表现-*」行 → 天气型定义表）；世界层决定"天气词汇表"
  （现实降雨 → 水晶雨），城市只提供参数。
- **远**：自定义日历（每月天数/年长，CSV 的 12 列假设泛化为 N 列）；
  自定义动画/滤镜/城市背景图；系统桌面替换；分享包格式（气候+世界+皮肤一个包）。
