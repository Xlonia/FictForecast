## 一、CSV 解析 —— scripts/climate_data.gd

**读取**：`FileAccess.get_csv_line()` 逐行解析——带引号字段、内嵌逗号天然安全；每行 ≥13 列才参与识别。

**清理**：每格 `trim_prefix("\uFEFF")`（去 BOM）+ `strip_edges()`——兼容 `"1.7 "` 这类带空格的引号数值。

**排布识别**（双排布自动）：
- `cleaned[0]` 能通过 `is_valid_float()` → **键在末列**：12 个月值 + 键 + [注释]（旧版 lioepprosia）
- 否则 → **键在首列**：键 + 12 个月值 + [注释]（m2 新版 myksolonia：`tmean,…"1.7 ",…,平均日均温,`）

**双 KEY_MAP**：中文键（平均日高温…）与英文语义 id（tmean/rmean/thigh/tlow/trecordh/trecordl/sunlight_h/raint/snowt/humidity）并列映射到语义键（high_temp/precip/…）。语义键是引擎唯一消费的稳定层——CSV 键名再怎么改，引擎不动。

**表头识别**：`_looks_like_month_header()`——12 个值恰好是 1…12 的整数即视为月份表头行跳过（同时兼容中文"月份"与英文 `month` 前缀表头）。

**空键行兜底**：第一列为空但 12 个值齐全的行（如「气候表现-晴天（高压气团）」逐月权重 0.05→2.0）——用**注释列名称**作为键保留进 `monthly` 并登记 `extra_keys`；连注释都没有才丢弃。

**残行处理**：任一月值 NaN → 整行跳过并 `skipped_rows += 1`（状态栏"跳过 N 行"）。加载永不中断。

**查询接口**：`month_value(key, month)`，缺失一律返回 `NAN`——下游全部 NAN 感知（UI 显示"—"、引擎跳过钳制）。

## 二、天气引擎 —— scripts/weather_engine.gd

**日期种子**：`hash("%04d-%02d-%02d" % [y,m,d])` → `RandomNumberGenerator.seed`。同一天任何时候生成结果完全一致（自检有断言）；真随机开关留待后续。

**跨月加权插值**（设计文档"两个月之间 15 天取加权值"的实现）：
```
from_start = day − 0.5          from_end = days − day + 0.5
w_own = clamp(min(from_start, from_end) / (BLEND_DAYS/2), 0, 1)   # BLEND_DAYS = 15
月首/月末与相邻月 lerp；月中央 w_own = 1 保持本月纯值
```

**日照 → 晴/阴/雨标定**（v1 唯一输入）：
```
s = 月日照时长 / 当月天数
p_rain   = clamp(0.55 − s×0.055, 0.05, 0.60)
p_sunny  = clamp((s − 2.0) / 9.0, 0.10, 0.75)
p_cloudy = 1 − p_rain − p_sunny（保证非负）
```
抽取：`roll = rng.randf()`，<p_sunny 为晴，<p_sunny+p_cloudy 为阴，否则雨。
已知偏差：7 月按日照只有 ~23% 雨概率，而气候表 raint=25.6 天——m3 改用 raint 作雨天先验，日照只区分晴/阴。

**气温合成**：跨月插值月值 → 当日整体距平 `randfn(0, 2.2)` + 高低温各自独立噪声 `randfn(0, 0.8)` → 天气型修正（雨：高温 −1.8~−3.4、低温 +0.6~+1.2；阴：高温 −0.8~−1.6、低温 +0.3；晴：高温 +0.6、低温 −0.3）。

**钳制顺序**：先对气象记录（跨月插值后的记录值）`high = min(high, rec_high)`、`low = max(low, rec_low)`，再 `low = min(low, high − 1)` 保证低温 < 高温。缺记录数据的月份自动跳过对应钳制。

## 三、世界随机搭台 —— scripts/world_rng.gd（未接入引擎）

**恒定历法双轨**（m2.1 批复口径）：
- 日期轨 `stable_day_number(y,m,d)`：自锚点 1970-01-02 起算的天数；锚点之前**绕锚点镜像折返**为正（1969-12-31 → 1），接缝连续单调——负 Unix 时间戳不复存在，日种子直接对应日期。
- 时间轨 `mirror_minutes(minute_of_day)`：当日分钟独立镜像，跨 00:00 不会把分钟换算进日期。
- （备选）`mirror_year()` 按年折返（批复示例口径 1862→2078；批复原稿 2108 为笔误）。

**世界名数字码** `name_code()`：世界文件名**逆序**后按 Unicode 码点做 Horner 折叠（基数 0x110000，掩码 2^31）——"逆编码 + 十进制化"，不同世界基底不同。

**三层种子** `world_seeds()`：year_seed = hash(名字码 | 日序(该年7月1日) | 1)，month_seed 同法取当月 1 日，day_seed 取当日——年度种子跨年才变，月度种子跨月才变，日期种子逐日变。

**城市噪点** `city_noise()`：FastNoiseLite（TYPE_PERLIN，seed=名字码），在**经度圆筒面**上采 3D 噪音：采样点 = (cosθ·1000, sinθ·1000, 纬度×10)，θ=经度角——±180° 经线天然连续。海拔不进噪音本体（批复：海拔做"特定时刻各日间同期的随机差异"，由引擎层使用）。

## 四、设置存取 —— scripts/settings_store.gd + mini_yaml.gd

**JSON**：`_load_json(path, defaults)` 把默认骨架与文件合并，逐字段 `_type_ok()` 类型校验（数字/字符串/字典/数组），坏字段回退默认——手改 JSON 弄错类型不会弄坏程序。保存统一 `JSON.stringify(data, "\t")`。

**目录**：`Worlds/<世界>.json` + `Worlds/<世界>.phenomena.json`（现象模板，挂世界——城市只能被影响，不参与现象种子）、`Cities/<城市>.json`（城市ID = CSV 文件名）、`Localization/zh.yaml`。

**MiniYaml**（受限子集）：顶层仅分组行"键:"，组内两空格缩进"键: 值"（值全文本、可选成对引号）；整行 # 注释；Tab 缩进/顶层键值/缺冒号→逐行报错列表；`dumps()` 按插入顺序序列化（Godot Dictionary 保序）。

## 五、编辑器 —— scenes/editor.tscn + scripts/settings_editor.gd

**运行形态（THX 惯例）**：场景根节点是普通 **Control**（整窗即编辑器），由 `open_editor.bat` / `-- --open-editor` / 主程序 spawn 独立进程启动；可拖动、缩放、关闭，与游戏主程序互不影响。主程序退出时**主动击杀**自己拉起的编辑器进程（`_kill_editor_process()`，挂在 NOTIFICATION_WM_CLOSE_REQUEST 与 _exit_tree 上）——是主程序的返回动作，不是子窗口连带。

**表单即状态**：SpinBox/LineEdit 的信号直接写**数据字典引用**（entry/current_world/loc_data），控件值变化 = 内存状态变化；「保存当前页」统一落盘。切换选择会重载磁盘数据（未保存改动丢弃，状态栏有提示）。

**行编辑器模式**：基准时间/基准日期/壁纸/效果/关系/关键帧都是"添加行 + ✕ 删除行"，每行闭包绑定数据字典，删除后整组重建。

**超前参数隐藏**：axial_tilt_deg / day_hours 两项在 tscn 与脚本中**注释隐藏**（m2.1 批复），JSON 默认骨架仍保留字段，下版本恢复即用。

## 六、主界面 —— scripts/main.gd

- 时间推进：`_advance_time(seconds×speed)`，跨 86400 秒折返 → `WeatherEngine.next_date()`（平/闰年）→ `_refresh_day()`；速度菜单 暂停~3600×；`FF_TIME_SCALE` 覆盖。
- 城市体系：扫描 `Climate/*.csv` → 菜单/状态栏显示名 = zh.yaml `cities.<id>`（缺失回退 capitalize）；切换城市重建 WeatherEngine。
- 状态栏：城市基础数据（Cities JSON：坐标/海拔/世界/时区）+ 机制声明 + 未映射键/跳过行数。
- 背景色：天气型基色 × 昼夜亮度曲线（5:00~7:00 晨 / 19:00~21:00 昏）。
- 测试钩子：`FF_FORCE_SKY`（强制晴/阴/雨）、`FF_OPEN_EDITOR`、`FF_EDITOR_TAB`。
